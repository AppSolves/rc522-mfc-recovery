# Changelog

## 0.1.0 - 2026-07-14

- Added a unified Typer and Rich CLI.
- Added automatic common-key and key-reuse checks.
- Added weak, hard, and static nonce classification.
- Generalized the Håkon Hystad weak-Nested acquisition path.
- Added validated RC522 Hardnested encrypted nonce and parity collection.
- Added Proxmark3 nonce-file conversion with parity-bit order correction.
- Added direct authentication verification for every recovered key.
- Added resumable state and JSON, CSV, MCT key, and raw dump exports.
- Added reproducible WiringPi and Proxmark3 setup scripts.
